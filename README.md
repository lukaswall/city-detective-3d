# City Detective 3D



A first-person 3D detective game for the browser, built for phones first (touch joystick, tap to inspect) and playable on desktop with arrow keys or WASD.



Three cases:

- The Emerald Deva (Bangkok): a stolen amulet.
- 
- The Last Ferry (Hong Kong): a murder.
- 
- The Missing Master (Berlin): a stolen master tape.
- 


No build step. Static files, three.js bundled.
